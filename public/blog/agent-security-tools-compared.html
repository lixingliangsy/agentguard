How to choose

  • Building guardrails now - start with AgentAegis for a fast prompt/tool risk read and a cited report.
  • Attacking your own agent - AgentRedTeam or PyRIT run adversarial scenarios you define.
  • Scanning a model endpoint - Garak probes a hosted model across vulnerability categories.
  • Open-source only - PyRIT (MIT) and Garak (Apache-2.0) are both permissively licensed.
